# Smithkit 0.1.1

This patch release improves label rendering and updates the npm README.

- Render grid, peripheral-scale, and radial-scale labels above all lines.
- Preserve label visibility, styling, and chart zoom behavior without blocking
  cursor tracking or marker dragging.
- Replace first-publication instructions with current npm installation and
  published-package usage examples.

The public API is unchanged.

## Installation

```sh
npm install smithkit@0.1.1
```

[Try the interactive demo](https://rosek86.github.io/smithkit/) or read the
[API documentation](https://github.com/rosek86/smithkit#readme).
