# Smithkit 0.1.0

The first Smithkit release provides interactive SVG Smith charts and independent
RF calculations for JavaScript and TypeScript applications.

[Try the interactive demo](https://rosek86.github.io/smithkit/).

## Included

- Impedance/admittance grids, constant-Q and VSWR circles, peripheral rulers, and
  independently mounted radial parameter scales.
- Stable trace/marker IDs, configurable points/lines, named traces, visibility,
  frequency selection, and marker comparisons.
- Fixed-view charts through `setZoomEnabled(false)`, with cursor readings and marker controls retained.
- Explicit marker-selection strategies when updating a trace, coalesced position
  events, and lifecycle cleanup through `destroy()`.
- One-port Touchstone 1.x parsing for RI, MA, and DB data, with frequencies in Hz.
- Positive-real reference impedance renormalization preserving physical impedance.
- DOM-independent RF readings, complex arithmetic, number formatting, and typed
  equivalent series-component calculations.
- ESM exports, TypeScript declarations, readonly sample inputs, and an independent
  integration example verified against the installed package.

## Installation after publication

```sh
npm install smithkit@0.1.0
```

See the [README](https://github.com/rosek86/smithkit#readme) for usage and the
[example](https://github.com/rosek86/smithkit/tree/main/examples/basic) for an
application using mount/update/resize/destroy. No library stylesheet is required.

## Scope

This is an initial 0.x release. Breaking changes will be documented in minor
releases; fixes use patch releases. The supported import is `smithkit`, with no
deep imports. The chart needs a browser; calculation and parser imports do not.
Touchstone 2.x, multiport measurements, and complex reference impedances are not
included. Computations use JavaScript binary64 precision.
