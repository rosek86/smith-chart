# Smithkit 0.3.0

This release adds report exports, shared appearance themes, and finer control over
grid detail and labels.

## Breaking API change

`GridLayer.setMinorVisible(boolean)` is replaced by
`setDetail('basic' | 'standard' | 'detailed')`:

- Replace `setMinorVisible(false)` with `setDetail('standard')`.
- Replace `setMinorVisible(true)` with `setDetail('detailed')`.
- Use `setDetail('basic')` for principal circles only. The default remains detailed.

## New features and improvements

- Export PNG with `Smith.toPng()` and `SmithScales.toPng()`. PNG and SVG exports
  support explicit dimensions, backgrounds, and combined reports with radial
  scales centered below the chart.
- Add independent trace and marker legends. Marker legends support selectable
  markers and readings: frequency, impedance, admittance, reflection coefficient,
  VSWR, and return loss. Descriptions wrap beneath the chart/scales.
- Export an explicit scale reading with a visible description without changing
  the live view. The demo selects a named marker or no readings, independently
  of the active cursor/marker tab.
- Configure chart, grid, scales, cursor, and marker appearance with shared light
  and dark themes and individual overrides. The library still defaults to light;
  the demo now starts in dark mode.
- Hide grid labels independently through `GridLayer.setLabelsVisible(boolean)`.
- Group demo chart settings and export options into separate accessible dialogs.
  The export dialog shares PNG/SVG options and defaults to 3200 px width.
- Organize SVG rendering behind the internal `SvgChartRenderer` while retaining
  the public chart API.

## Installation

```sh
npm install smithkit@0.3.0
```
