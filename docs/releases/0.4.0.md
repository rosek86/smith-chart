# Smithkit 0.4.0

Configure charts through one grouped options object, update settings with
`setOptions()`, and explore the API through a navigable integration gallery.

## Breaking changes

- Replace `new Smith(referenceImpedanceOhms, appearance)` with `new Smith(options?)`.
  Options group `appearance`, `interaction`, `grid` (including `grid.layers`),
  `circles`, and `peripheralScales`, with `referenceImpedanceOhms` at the top level.
- Charts now default to a standard impedance grid with labels. Peripheral scales,
  zoom, and cursor tracking are disabled; admittance and Q/VSWR layers remain hidden.
- `addTrace()` no longer creates a marker. Add markers explicitly with
  `addMarker(traceId, sampleIndex?)`.
- Visibility/label setters require booleans, unknown structural configuration keys
  are rejected, and `scaleReadout` in chart exports requires included `scales`.

See the [migration guide](https://github.com/rosek86/smithkit/blob/v0.4.0/docs/migration-0.4.md)
for equivalent configuration and marker setup.

## New features

- `setOptions(SmithOptions)` patches supplied fields without resetting omitted
  settings. It validates the complete update before mutation and renormalizes
  existing data when the reference impedance changes.
- `setGridDetail()` updates all four grid layers together. `CircleLayer.setValues()`
  replaces Q/VSWR values with validation, input copying, and duplicate removal.
- `setCursorEnabled()` controls cursor geometry and readings independently of zoom
  and markers; disabling cancels pending readings and clears the readout.
- The demo links to a gallery of runnable static chart, marker control, theme,
  export, and lifecycle examples. Each page displays the source it executes.
- The API review documents configuration precedence, events, errors, export behavior,
  and the compatibility scope intended for 1.x.

## Installation

```sh
npm install smithkit@0.4.0
```
