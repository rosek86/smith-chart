# Smithkit 0.5.0

This release expands measurement import and export, reduces the cost of large
traces, and adds finer control over peripheral scale labels.

## Measurement data and Touchstone

- Pass object samples, `[frequencyHz, re, im][]`, or packed `Float64Array` triples
  to `addTrace()` and `updateTrace()`. Inputs are copied into owned packed storage.
- Read Touchstone 1.x `.s2p` with explicit S11/S22 selection. The parser continues
  returning object samples by default; `output: 'packed'` writes directly into
  a `Float64Array` without intermediate sample objects.
- Write reflection data to `.s1p` using `Touchstone.stringify()`, in Hz/RI with an
  explicit reference impedance. Packed samples can also be renormalized using
  `RfCalculations.renormalizeSamples()`.
- Two-port import extracts a single reflection trace. Full network renormalization,
  noise blocks, and Touchstone 2.x remain outside the supported scope.

## Large traces

- Opt into `lineTolerancePx` to simplify displayed SVG lines in pixel space.
  Cached detail levels adapt to zoom and resize; measurements and markers retain
  full-resolution samples.
- Choose `lineDetail: 'full' | 'view'` for SVG/PNG exports; the default is `full`.
- Accelerate marker lookup while preserving nearest-sample selection and tie
  behavior. Noisy million-point SVG paths can still be expensive to render.

## Appearance and examples

- Control peripheral scale captions and numeric ticks independently.
- Adjust chart settings beside the marker/cursor panel on desktop.
- Explore the reordered gallery, including Touchstone import/renormalization/export
  and large traces with up to one million samples.
- Improve select control styling in the demo and examples.

## Compatibility and installation

Existing object-based trace inputs and default Touchstone `.s1p` parsing remain
supported. Line simplification is opt-in. No migration is required from 0.4.x.

```sh
npm install smithkit@0.5.0
```

See the [README](https://github.com/rosek86/smithkit/blob/v0.5.0/README.md)
for the public API and the [demo](https://rosek86.github.io/smithkit/)
for runnable examples.
