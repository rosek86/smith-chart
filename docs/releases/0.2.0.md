# Smithkit 0.2.0

This release adds keyboard and touch marker controls, standalone SVG export, and
more readable chart scales.

## Breaking API changes

Standalone calculation, parsing, formatting, and comparison functions are replaced
by static methods on `RfCalculations`, `Touchstone`, `SmithFormatter`, and
`MarkerMeasurements`. Update imports using the
[migration guide](https://github.com/rosek86/smithkit/blob/v0.2.0/docs/migration-0.2.md).
Arguments, units, and return types remain unchanged.

## New features and improvements

- Select markers with Tab and navigate samples using arrows, Shift+Arrow,
  Page Up/Down, and Home/End. Visible focus, accessible readings, and 44 px touch
  targets improve marker interaction. Use `focusMarker` and `MarkerSelect` to
  connect external controls.
- Keep markers and their focus indicators above chart labels.
- Export standalone SVG with `Smith.toSvg()` and `SmithScales.toSvg()`;
  the demo includes separate download buttons.
- Adapt grid labels to available space while preserving key axis values and
  keeping label selection stable during zoom.
- Group peripheral rulers into phase and electrical-length bands with complete
  captions and values.
- Preserve overlapping trace order when updating samples, and reorganize library
  internals around class responsibilities.

## Installation

```sh
npm install smithkit@0.2.0
```
